# Market Segmentation Analysis of McDonald's

## Overview
This project performs a detailed market segmentation analysis using McDonald's customer dataset. The goal is to identify customer segments based on demographic and purchase data to optimize marketing efforts and develop targeted strategies.

## Files Included
- mcdonalds_segmentation.ipynb – Jupyter notebook with complete segmentation code.
- mcdonalds.csv – Dataset containing customer responses (originally used in the R-based case study).

### Key Features:
- Clustering techniques for market segmentation (e.g., K-means, DBSCAN).
- Analysis of key customer demographics (age, gender).
- Insights into McDonald's consumer behavior for personalized marketing strategies.
- Real-world applicability in business strategy and marketing in the fast food industry.

## Prerequisites
- Python 3.x
- Libraries: pandas, numpy, scikit-learn, matplotlib, seaborn
- Jupyter Notebook (for interactive analysis)
